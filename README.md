# tizenbrew-magicmirror

A [TizenBrew](https://github.com/reisxd/TizenBrew) module that opens a MagicMirror instance on the LAN
full screen on a Samsung Tizen TV (tested target: 2019 RU8200, Tizen 5.0).

Install: in TizenBrew, add the module `gameforce/tizenbrew-magicmirror`.

The URL lives in `package.json` (`websiteURL`). `main.js` only hides the pointer and reloads every 6 hours.
